# SCBE Docs Archive

> Historical documentation corpus extracted from [SCBE-AETHERMOORE](https://github.com/issdandavis/SCBE-AETHERMOORE) as part of the monolith cleanup.

This repo preserves the high-value documentation files (claims audits, evidence ledger, architecture notes, buyer proof checklist) that used to live in `SCBE-AETHERMOORE/docs/`. The main repo now focuses on code; long-form docs live here.

## Most important files

- **[CLAIMS_AUDIT_V4.md](CLAIMS_AUDIT_V4.md)** — per-claim evidence ledger (proven / caveated / disproven)
- **[CLAIMS_EVIDENCE_LEDGER.md](CLAIMS_EVIDENCE_LEDGER.md)** — patent claims with evidence status
- **[BUYER_PROOF_CHECKLIST.md](BUYER_PROOF_CHECKLIST.md)** — what to send a buyer
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — full architecture reference

For the condensed, HTML-rendered version of this material, see [aethermoore.com/research/evidence.html](https://aethermoore.com/research/evidence.html).
